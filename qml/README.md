# Meridian for Qt Quick

The QML module `Meridian` (in `Meridian/`), its Qt Quick Test suite (`tests/`),
the gallery (`gallery/`) and review tooling (`tools/`). See
[the QML guide](../design/project/guides/50-qml.md).

```bash
python3 tool/generate_qml.py      # regenerate Tokens, ColorScheme, TypeScale, Metrics, IconData, fonts
tool/verify_qml.sh                # check, lint, test
qml -I qml qml/gallery/main.qml   # run the gallery
```

Files carrying the `GENERATED by tool/generate_qml.py` header are never edited
by hand.

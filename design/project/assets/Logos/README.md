# App marks

Each app's mark, copied byte for byte from its repository. Use a mark only on welcome and About screens, splash screens and platform icons: never inside the working UI, never recoloured, never redrawn. There are no wordmarks; set the app's name in `display` next to the mark.

- `gitlama-mark.svg`: the cream llama on the cerulean square (`#056CB3`, the GitLama `accent` token). Source: GitLama `assets/brand/icon.svg`.
- `crossproton-mark.svg`: the folded-envelope stroke in white on the violet square (`#6D4AFF`) with the lime privacy spark (`#DDE300`). The 92px transparent border is the macOS safe area. Source: `CrossProton/assets/branding/crossproton_app_icon.svg`.
- `mimameidr-mark.svg`: the liquid-glass teal plate with the process-tree M. Source: `Mimameidr/resources/logo/mimameidr-icon.svg`.
- `nibluma-mark.svg`: the white `n` and book baseline on navy (`#18304F`, the Nibluma `brand` token). Source: `Nibluma/resources/brand/nibluma-app-icon.svg`.
